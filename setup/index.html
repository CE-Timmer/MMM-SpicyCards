MMM-SPOTIFYCARDS

A little setup.
A lot of music.

Connect your listening and bring the words to your cards.

01

Connect the lyrics

Checking…

Sign in directly on Spotify in a dedicated browser window. Once Web Player is ready, we’ll save its access token for Spicy Lyrics.

The login window opens on this computer. Your password is entered only on Spotify.

The saved token is used by Spicy Lyrics’ service to retrieve lyrics. When it expires, use this button again. Your dedicated browser profile keeps your Spotify sign-in.

Already have a web-player token?

Use a token from your own Spotify Web Player session. A developer app token is not a replacement.

02

Playback connection

Checking…

The cards can use your saved Web Player session for playback too. No developer app is needed for that route; Spotify must accept the session for playback access.

Optional: a separate playback login with automatic token refresh

Use your own developer app for a separate user authorization. This connection renews playback access without renewing the web-player token used for lyrics.

In your Spotify developer app, add this exact redirect URI:

http://127.0.0.1:8888/callback
Credentials are saved privately on this computer. The cards never receive your tokens.
